# SiteStory – from a site walk-through video to reports, chronicle and marketing

**Team: Process Team Two** · BizHack AI Hackathon 2026, Budapest

**BizHack AI Hackathon 2026 · Challenge 02 · BOFF NWT (NWT group) · Category: Capacity**

## The problem
Site managers photograph ~25 running construction projects every week (10–30 photos each), store them on a server and type a progress report for the customer by hand. After that the material is lost: it is not shown at the weekly site inspection meeting, management has no overview, and it very rarely reaches the website or social media, because marketing would need ~3 hours a day for it.

## Baseline → result
| Who | Today | With SiteStory |
|---|---|---|
| Site manager | 2 h / week (1 h photos + 1 h typing the report) | **~15 min / week**: one 1–2 min walk-through video with spoken commentary per project |
| Marketing | 3 h / day needed (so it doesn't happen) | **≤ 30 min / day**: approve or reject ready drafts |
| Site inspection meeting | photos and status not prepared | project page ready on screen, 0 min prep |
| Management | ask every site manager | one weekly summary + document checklist |
| Facts in drafts | – | every number automatically checked against the sources |

`scripts/run_demo.py` writes the measured processing times to `output/metrics.md`.

## What it does
```
Site manager's phone: 1–2 min walk-through video ("what's new this week")
        │ upload (Lovable app)
        ▼
n8n  01_weekly_site_report
   ElevenLabs Speech-to-Text → timestamped transcript
   OpenAI (text + photos)    → customer report · chronicle entry · social draft EN/CZ · best photo · issues
   Guardrails (code)         → every number must appear in transcript/notes, client-name consent, photos with faces/plates flagged
        ▼
Lovable app (SiteStory)
   Upload · Project page (customer, inspection meeting, chronicle, PDF) · Marketing inbox (approve/reject) · Management
        ▲
n8n  02_management_summary
   document checklist from the project folder (signed contract? building office approval? new project?)
   + OpenAI one-page summary for CEO and head of construction
```

## Run it (≈10 minutes)
**You need:** an n8n instance (cloud or self-hosted), an OpenAI API key, an ElevenLabs API key (only for video), Python 3.9+.

1. **Create the workflows**: with the n8n MCP server / Workflow SDK from `n8n/sdk/*.ts`, or import the plain JSON `n8n/01_weekly_site_report.json` and `02_management_summary.json` (*Workflows → Import from file*; this older JSON variant calls OpenAI through HTTP Request nodes).
2. **Credentials**:
   - OpenAI: an *OpenAI* credential (or n8n AI credits) in the OpenAI nodes; for the JSON variant a *Header Auth* `Authorization: Bearer sk-...`
   - ElevenLabs (only for videos): a credential that sends header `xi-api-key: <your key>` in "ElevenLabs speech-to-text"
3. **Activate** both workflows (toggle top right). The webhooks are then
   `https://<instance>/webhook/site-report` and `.../webhook/management-summary`.
4. **Run the demo** on the sample data:
   ```bash
   python scripts/run_demo.py --n8n https://<instance>/webhook
   ```
   Open `output/management_summary.md`, `output/marketing_inbox.md`, `output/projects/*.md`, `output/metrics.md`.
5. **With a real video** (public URL, e.g. from Lovable storage):
   ```bash
   python scripts/run_demo.py --n8n https://<instance>/webhook --project 02_BESS_container --video-url https://.../walkthrough.mp4
   ```
6. **The app**: create a Lovable project, paste `lovable/PROMPT.md` message by message, set the secret `N8N_WEBHOOK_BASE`.

Test one call by hand:
```bash
curl -X POST https://<instance>/webhook/site-report -H "Content-Type: application/json" -d '{
  "project": {"name": "Test", "company": "AGRO NWT", "consent_name_allowed": false, "client_name": "Client B",
              "notes": "Container BESS 500 kW / 1 MWh"},
  "week": "2026-W47",
  "transcript": "[00:05] New this week: the battery container arrived and the crane set it on the slab."}'
```

## Answers to the challenge owner's questions
| Question | Answer |
|---|---|
| Short video with comments on site? | Yes – it is the only input; ElevenLabs turns speech into a timestamped transcript. |
| One file with all photos and text per project, for the customer and the inspection team? | Project page in the app (print / PDF) and `output/projects/<project>.md`. |
| Summary of all projects for management? | Workflow 02 + Management page. |
| Same page as the project chronicle? | Yes – weekly entries stay on the project page as a timeline. |
| All photos on the reference page? | Yes in the app (gallery). Publishing to the public website (CMS) is not automated: marketing copies the approved draft. |
| One photo + text per project for web/social, marketing decides? | Marketing inbox, with automatic fact check. |
| Easy upload of new videos? | Upload page in the app, works from the phone. |
| Folder scan: new project, signed contract, building office approval? | Workflow 02 checks the documents of every project and flags missing items. |

## Limits and next steps
- Key frames from the video (stills at the transcript timestamps) need ffmpeg – planned; today photos are uploaded next to the video.
- Reading the company file server (drive S:) needs a small sync agent or n8n self-hosted inside the company network.
- Automatic posting to LinkedIn/Instagram is out of scope on purpose (platform terms); drafts are copy-ready.
